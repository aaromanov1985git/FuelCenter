# Автозапуск Docker-стека GSM в Windows

Чтобы контейнеры плавно останавливались при остановке службы и поднимались при старте системы.

## Что уже настроено в docker-compose.yml

- **Плавная остановка:** у каждого сервиса задан `stop_grace_period` (10–15 с). При `docker compose stop` контейнеры получают SIGTERM и успевают корректно завершиться.
- **Перезапуск:** `restart: unless-stopped` — после перезапуска Docker или ПК контейнеры поднимутся снова, если перед этим был выполнен `docker compose up -d`.

## Автозапуск при старте Windows

Чтобы стек поднимался при каждой загрузке системы:

### Вариант 1: Планировщик заданий (рекомендуется)

1. Открой **Планировщик заданий** (taskschd.msc).
2. **Создать задачу** (не «Простую задачу»).
3. Вкладка **Общие:**
   - Имя: `GSM Docker Compose`
   - Выполнять с наивысшими правами (по желанию).
   - Настроить для: Windows 10/11.
4. Вкладка **Триггеры** → **Создать:**
   - Начать задачу: **При запуске**.
   - Задержка: 30–60 секунд (чтобы успел запуститься Docker Desktop).
5. Вкладка **Действия** → **Создать:**
   - Действие: **Запуск программы**.
   - Программа: `powershell.exe`.
   - Аргументы: `-NoProfile -ExecutionPolicy Bypass -File "C:\curWork\GSM\scripts\docker-start.ps1"` (путь замените на свой к каталогу проекта).
6. Вкладка **Условия:** снимите «Запускать только при питании от электросети», если нужно запускать и от батареи.
7. Сохраните задачу.

После перезагрузки контейнеры поднимутся автоматически (с учётом задержки).

### Вариант 2: Ярлык в автозагрузке

Создайте ярлык с целью:

```text
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\curWork\GSM\scripts\docker-start.ps1"
```

Поместите ярлык в папку автозагрузки (Win+R → `shell:startup`).

## Плавная остановка

Перед выключением ПК или остановкой «службы» лучше сначала остановить контейнеры:

```powershell
cd C:\curWork\GSM
.\scripts\docker-stop.ps1
```

Скрипт выполняет `docker compose stop -t 30` (дать до 30 с на завершение), затем `docker compose down`.

Либо вручную:

```powershell
docker compose stop -t 30
docker compose down
```

## Полезные команды

| Действие              | Команда                          |
|-----------------------|----------------------------------|
| Запуск стека          | `.\scripts\docker-start.ps1` или `docker compose up -d` |
| Плавная остановка     | `.\scripts\docker-stop.ps1`      |
| Только остановка      | `docker compose stop -t 30`      |
| Статус контейнеров    | `docker compose ps`              |
| Логи                  | `docker compose logs -f`         |
