НА НОВОМ СЕРВЕРЕ:

1. Скопировать всю директорию migration_backup на новый сервер

2. Установить Docker Desktop для Windows

3. Клонировать репозиторий или скопировать файлы проекта

4. Восстановить .env файл:
   copy migration_backup\backend.env.backup backend\.env

5. Запустить Docker Compose:
   docker-compose up -d

6. Восстановить базу данных:
   docker cp migration_backup\gsm_backup_migration.dump gsm_db:/tmp/
   docker exec gsm_db pg_restore -U gsm_user -d gsm_db -c /tmp/gsm_backup_migration.dump

7. Применить миграции:
   docker exec gsm_backend alembic upgrade head

8. Проверить работоспособность:
   http://localhost:8000/health
